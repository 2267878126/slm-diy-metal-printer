# SLM-DIY-Metal-Printer

桌面级SLM（选择性激光熔化）金属3D打印机 DIY 项目 —— 1万元预算内的消费化金属制造探索。

## 项目简介

金属增材制造长期被百万级工业设备垄断。2025年起行业出现桌面化浪潮（国产桌面SLM下探10万级），2026年消费级产品（探雪科技SnowPod等）进一步把金属打印做成"白色家电"。本项目以1万元预算为目标，借鉴消费级产品的"安全闭环、粉末不接触人、易用软件"设计思路，基于开源社区资料（大狗嚼SLM100），自研组装一台桌面级SLM金属打印机。

**核心亮点**：
- 1万元级成本，对比商业桌面SLM（10万级）降低一个量级
- 借鉴SnowPod产品化思路：封闭粉末循环、HEPA过滤、双门取件、易拆支撑
- 智能车辆工程学科交叉：机械/控制/嵌入式 × 增材制造/材料/光学

## 目标规格

| 项目 | 指标 |
|---|---|
| 成型空间 | 80×80×100 mm |
| 激光器 | 200W光纤激光器（二手/国产渠道） |
| 光斑 | 40μm级 |
| 材料 | 316L不锈钢起步，扩展铜合金 |
| 粉末回收 | ≥80% |
| 氧含量控制 | <0.1%（惰性气体保护） |

## 技术路线

- 机械结构：基于开源SLM100图纸（嘉立创钣金+机加工）
- 光学系统：光纤激光器 + 数字振镜 + F200场镜
- 电气控制：STM32H7固件 + 上位机（串口115200，PWM控制激光）
- 气体安全：氩气气路 + 氧含量联锁 + HEPA过滤 + PM2.5监测
- 软件工艺：Cura 5.11 SLM配置 + 自建工艺参数矩阵
