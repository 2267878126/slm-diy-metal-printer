# 桌面级SLM金属打印机 DIY 项目方案
**（借鉴探雪科技 SnowPod 产品化思路，以大狗嚼 SLM100 开源资料为机械基础）**
版本：v1.0 ｜ 日期：2026-10-17 ｜ 预算目标：1 万元以内

---

## 0. 项目定位

做一台"消费级体验、桌面级安全"的 SLM 金属打印机，不是复刻工业机，而是把以下三件事做到位：

1. **粉末安全闭环**（借鉴 SnowPod 核心）：加粉像换粉盒、回收像吸尘器、取件不接触粉末。
2. **封闭式小型化**：整机控制在桌面级，密封舱+双门结构。
3. **可迭代的工艺平台**：先跑通运动/控制/安全链路，激光器与工艺参数分阶段升级。

目标规格（对齐 SnowPod 量级）：

| 项目 | 目标值 |
|---|---|
| 成型空间 | 80×80×100 mm |
| 激光器 | 200W 光纤激光器（二手/国产渠道） |
| 光斑 | 40μm 级（由振镜+场镜配置决定） |
| 材料 | 316L 不锈钢起步，后续扩展铜合金 |
| 粉末管理 | 封闭循环 + 90% 级回收 + HEPA 过滤 |
| 气体 | 惰性气体保护（氩气瓶起步，氮气发生器为远期升级） |

## 1. 从 SnowPod 提炼的 6 条设计原则（DIY 落地版）

| SnowPod 的做法 | DIY 落地方式 |
|---|---|
| 封闭式粉末循环，加粉像换复印机粉盒 | 自制"粉盒+漏斗"上粉机构；打印后吸尘器抽粉回收到粉瓶，粗筛网过滤后可复用 |
| 双层门 + 转运盒取件，用户不接触粉末 | 密封舱做双层门，内门后加取件转运盒（打印平台升起、刮刀推出工件） |
| HEPA13 双滤芯 + HEPA14 医用滤芯，PM2.5 实时监测 | 购买 HEPA 滤芯组件自制过滤箱（排风口），加装 PM2.5 传感器模块（淘宝几十元） |
| 200W 光纤激光器 + 40μm 光斑 | 二手/国产 200W 光纤激光器 + F200 场镜 + 数字振镜（BOM 已有：振镜套装 700 元、场镜 600 元） |
| 专利易拆支撑（薄熔覆层 + 网格结构） | 工艺层实现：小层厚打印 + "纵向强、横向弱"网格支撑，钳子即可拆除 |
| 免费切片软件、消费级操作 | 手头已有：Cura 5.11 + SLM 专用配置 + 上位机 exe，先黑盒使用，后续可自研 |

## 2. 系统架构（五大子系统）

### 2.1 机械系统 —— 底子最厚
- 直接采用本地资料：`桌面级SLM 100 大狗嚼.step` + 嘉立创钣金 4 件套（侧板/前面板/顶板底板/背板）下单加工。
- 内部子系统参考 2020 SolidWorks 工业级图纸（218 零件）：成型仓（丝杆 R16-5T3-FSI）、送粉仓（双仓+传感器）、刮刀机构、循环气体装配。
- 铺粉/送粉轴可选用手头谐波减速器（30:1/32:1）或摆线减速器（20:1）复刻件——但**先确认用途归属**（资料未说明装在哪根轴），装配前必须核对。

### 2.2 光学系统 —— 预算与性能的核心矛盾点
| 配置 | 预算 | 说明 |
|---|---|---|
| 方案A 入门验证 | 约 400 元 | 20W 450nm 蓝光激光（BOM 有），先跑通全链路，适合铜合金/薄层试验 |
| 方案B 目标配置 | 3000~6000 元 | 二手/国产 200W 光纤激光器，对齐 SnowPod，能打不锈钢 |
| 扫描系统 | 700+600 元 | 数字振镜套装 + F200 场镜（BOM 已有价格） |
| 光路辅助 | 300~500 元 | 准直镜/扩束镜/防护镜片 |

**结论**：1 万预算下激光器是唯一决定成败的大件。推荐**先按方案B询价**（二手 200W 光纤 3000 元左右有机会），若超预算则先方案A跑通再升级。

### 2.3 电气与控制 —— 黑盒风险区
- 手头：STM32H723/H743 固件（bin/hex）、上位机 exe（4 版）、引脚定义.txt、振镜电路原理图。
- 缺口：**无整机接线图、无固件源码、无上位机源码/协议文档**。
- 行动：先用现有固件+exe 做黑盒验证（串口 115200，PWM 1-20kHz）；同时向博主索取固件工程与接线图——拿不到源码则需自行基于 STM32H7 开发（工作量 1~3 个月，这是最坏情况）。

### 2.4 粉末循环与安全 —— 本项目第一优先级
- 密封舱：沿用图纸舱体，装配后做气密测试（肥皂水/压力表法）。
- 上粉：粉盒化设计（漏斗+闸阀），加粉在舱外操作。
- 回收：工业吸尘器（防爆型更佳）+ 筛网分选，粉末复用前必须过筛并标记循环次数。
- 过滤：HEPA 滤芯自制过滤箱，排风口出风比进风干净为目标。
- 监测：PM2.5 传感器 + 氧含量分析仪（图纸已有模型）。
- 联锁：急停、门锁（开门断激光）、激光防护窗，**必须通电试机前全部就位**。

#### 2.4.1 借鉴激光复印机粉末处理架构（可行性已评估，方向可行）
激光复印机成熟可靠地解决了"细微粉末的密封存储、定量输送、防泄漏、废粉回收"四大问题，与 SLM 金属粉末处理的痛点高度重合，**借鉴其系统架构、不搬其静电显影机理**，落地为本项目粉末子系统设计参考：

| 复印机碳粉系统组件 | 借鉴到 SLM 金属粉末系统的设计 | 本项目落地要点 |
|---|---|---|
| 密封墨粉盒（插入即用） | **金属粉盒化**：一次性密封粉盒+快速插拔接口，换粉在舱外进行 | 粉盒含漏斗+密封法兰；对标 SnowPod 换粉逻辑，避免开舱暴露粉末 |
| 粉盒内搅拌器（防碳粉结块） | 粉盒内置搅拌桨/振动器 | 金属细粉长期静置易团聚，搅拌保持流动性；电机低速防扬尘 |
| 粉量检测（芯片/视窗/光电） | 粉盒重量传感器 + 视窗液位观察 | 缺粉自动暂停打印，避免空铺粉层烧穿成型件 |
| 出粉定量机构（显影辊/供粉辊） | **螺旋给料器 + 闸阀**控制出粉量 | SLM 铺粉精度 μm 级，需定量给料至刮刀机构，不能直接照搬复印机出粉口 |
| 废粉回收仓（废粉不回流） | 独立废粉仓 + 筛分回路 | 金属粉价格高必须回用：过 100 目筛 + 标记循环次数，复用前混入 20%~30% 新粉 |
| 全封闭供粉通路 | 密封粉路 + 负压管道 + HEPA 过滤箱 | 复印机防的是粉尘污染，本项目防的是金属粉尘爆炸与吸入，负压方向必须明确 |
| 静电显影转移 | **不采用** | SLM 靠刮刀物理铺平，无需静电转移；金属粉末易爆，静电场反而危险 |

**关键差异（必须保留 SLM 自身体系的部分）**：
- 惰性气体保护：碳粉不氧化不燃爆，金属粉必须在氩气环境（氧含量 <0.1%）操作，粉盒接口需通氩气置换。
- 粉末粒径与密度：碳粉 5~10μm 轻飘；金属粉 15~53μm 球形重质，扬尘机制不同，负压回收风量需按金属粉标定。
- 回收再利用：复印机废粉直接废弃，SLM 废粉必须过筛回用（成本决定），需记录循环次数防氧化劣化。

**结论**：复印机粉末处理"全密封+粉盒化+废粉回收+防泄漏"的架构思路**可直接作为本项目粉末子系统设计蓝图**，配合螺旋定量给料与氩气保护即可满足 SLM 需求，且与探雪 SnowPod 的封闭粉末循环方案方向一致，可行性高。

### 2.5 气体系统
- 起步方案：**氩气瓶 + 减压阀 + 流量计**（总成本 500~1000 元），比制氮机便宜得多。
- 远期升级：99.9% 纯度制氮机（对齐 SnowPod，约数千元），实现"插电即用"。
- 控制：氧含量传感器闭环——氧浓度高于阈值（建议 <0.1%）自动停止激光。

### 2.6 软件与切片
- 手头已有 Cura 5.11 + SLM 配置（层厚 0.05mm、线宽 0.1mm、速度 1200mm/s）与 14 个测试 Gcode。
- 注意：现有 Gcode 是 FDM 路径（M104/M109 等加热指令会被上位机忽略），**激光功率由上位机统一设定，不随 Gcode 变化**——这限制了分区变功率打印，属可接受折中。
- 工艺参数矩阵（功率-速度-层厚-扫描间距）需自行调试积累，无现成参考。
