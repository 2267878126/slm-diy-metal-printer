## 4. 关键事实（已核实，可作为论述依据）

### 4.1 商业与竞品
| 对象 | 情况 |
|---|---|
| 铬莱铂 GLB-120M | 国产商业桌面 SLM，约 **9.9 万** |
| 美光速造 DeskFab X1 | 同类，约 **10 万** |
| 探雪 SnowPod（融速科技子公司） | 2026-09 发布：整机 360×360×660，成型 80×80×100，200W 光纤，光斑 40μm，主打 316L，封闭粉末循环 + HEPA 双滤芯，11 月 Kickstarter；**粉末处理借鉴激光打印机** |
| re AM250（慕尼黑工大） | 较成熟开源，预算约 4 万，超预算，仅参考 |
| 上海产研院同轴送丝 | DED 路线，退路备选 |

> 结论：**商业桌面 SLM 最低约 9.9 万，1 万只能 DIY。**

### 4.2 大狗嚼 SLM100（主参照）
- 资料：`D:\BaiduNetdiskDownload\大狗嚼SLM100分享给粉丝的资料\`（压缩包 569MB，457 条目，344 个建模文件）
- 机械图纸约 **80%**：SolidWorks 2020 共 247 个（sldprt×207 / sldasm×40）；整机 STEP 含 `SLM_V2 GPT6版本.step`（3.1MB）；嘉立创钣金 4 件套；Fusion 总装图 `工业级SLM总装图.f3d`；摆线/谐波减速器模型
- 整机 STEP 结构：850×570 外框、30×35 型材、四立柱、送粉缸+成型缸双丝杠传动、刮刀铺粉、光路支架、前门合页锁扣、背板电控
- **已知短板**：BOM 仅 13 行、无整机接线图、固件/上位机为无源码黑盒、无工艺参数表、惰性气体只有模型无控制策略、激光源 300W 泵浦、**目前只打印过树脂**

### 4.3 原理
- SLS = 部分熔化烧结（尼龙为主，有孔隙）；SLM = 完全熔化（金属，致密度 99%+，需惰性气体，氧 <0.1%）
- 金属粉 15–53μm；SLM 对功率/氧含量/防爆要求远高于 SLS；激光安全 4 级

## 5. 方案定稿方向

- 五大子系统：机械 / 电气 / 安全 / 光学 / 工艺
- 激光：方案 A 20W 蓝光先验证全链路；方案 B 二手 200W 光纤约 3000–5000 元一步到位
- 粉末处理（核心创新，借鉴激光复印机）：密封粉盒插拔换粉、粉盒搅拌防结块、螺旋给料+闸阀定量、负压+HEPA 防爆、**废粉过筛混 20–30% 新粉回用**；不可照搬静电显影（金属粉易爆，靠刮刀）
- 安全底线：密封舱 + 氩气瓶（比制氮机便宜一个量级）+ 氧含量联锁停激光 + HEPA
- 里程碑 M0–M6：机械装配→电路→安全→光学校准→工艺调试→稳定打印；装起来约半年，首件金属件 1–1.5 年，稳定 1.5–2 年

### 6.3 已修复问题（防止复发）
| 问题 | 根因 | 修法 |
|---|---|---|
| CGAL "mesh is not closed" | 凹截面 linear_extrude 多副本 union 退化 | 细型材改用 cube 方柱；梁端与立柱留 0.5mm 间隙 |
| 整机骨架整体偏移 -20mm、角件外飘到 860/580 | **4040/3030 截面以中心为原点**，而立柱按左下角摆放 | 立柱加 `+POST/2` 偏移；角件重算 ax/ay/bx/by |
| 角件与横梁共面非流形 | 角件 z 从 h+2 起 | 下移到 h-1，装在梁下方 |
| 面板朝向错、侧板悬空 | rotate 角度不对称 | 左板 `rotate([0,0,-90])`、右板 `translate` 改 `POST-10` + `rotate([0,0,90])` |
| 仓板穿入顶部光路层 | 板高取 CH_H | 改 PH = CH_H-15 |
| 光纤线缆伸出顶面、激光头超 700 | 向上引线、头高 55 | 线缆水平引向背板、头高 50 |
| 脚杯 φ50 超出 X 零位 | 脚杯中心在立柱中心 | 改 φ40 |
| 铺粉导轨方向反 | rotate 轴向错 | 修正 recoater_assy |
