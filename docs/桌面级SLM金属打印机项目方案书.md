## 一、项目背景与意义

### 1.1 背景
金属增材制造（SLM，选择性激光熔化）是当前制造业最前沿的方向之一，但工业级设备长期处于"百万级价格、厂房级场地、专业级操作"的壁垒中。2025年起行业出现明显"桌面化"浪潮：国产厂商将桌面SLM下探至10万元（美光速造DeskFab X1、铬莱铂GLB-120M）；2026年探雪科技SnowPod等消费级产品进一步把金属打印做成"白色家电"。与此同时，开源社区（如大狗嚼SLM100）已有DIY玩家尝试以3000元级成本手搓桌面SLM设备。

### 1.2 与专业方向的结合点
智能车辆工程的核心课（机械设计、单片机/嵌入式、自动控制、传感器、C/C++）恰好覆盖SLM设备的机械、电气、控制三大子系统。本项目是以车辆工程底层能力为基础，向增材制造交叉方向的一次完整工程实践，具备鲜明的学科交叉特征。

### 1.3 意义
- **工程实践价值**：完整经历"设计→加工→装配→调试→工艺→迭代"全链条，锻炼综合工程能力。
- **技术探索价值**：验证1万元级消费化SLM的可行性，积累工艺参数数据。
- **行业价值**：对标行业"桌面化"趋势，探索金属制造普惠化路径。

## 三、技术路线

### 3.1 总体方案
借鉴探雪科技SnowPod的"消费级产品化"设计思路（粉末安全闭环、用户不接触粉末、易拆支撑、免费软件），以大狗嚼SLM100开源资料（机械图纸齐全度约80%）为机械基础，自行补齐电气、控制、工艺三大缺口。

### 3.2 五大子系统

| 子系统 | 方案 | 来源/状态 |
|---|---|---|
| 机械结构 | 密封舱+成型仓+送粉仓+刮刀机构，嘉立创钣金加工 | 开源图纸（较完整） |
| 光学系统 | 二手200W光纤激光器（备选：20W蓝光入门）+数字振镜+F200场镜 | 需采购/装调 |
| 电气控制 | STM32H7固件+上位机exe，串口115200，PWM控制激光 | 黑盒验证，争取源码 |
| 气体与安全 | 氩气瓶气路+氧含量联锁+HEPA过滤+PM2.5监测 | 需自行设计 |
| 软件工艺 | Cura 5.11 SLM配置+上位机，工艺参数矩阵自行调试 | 雏形已有 |

### 3.3 关键技术难点
1. 激光光学装调（光路对中、振镜标定、场镜畸变校正）
2. SLM工艺参数调试（功率-速度-层厚-间距矩阵）
3. 金属粉末安全与惰性气体保护（防爆、防氧化）
4. 开源固件/上位机为黑盒，需逆向或自行开发
